# Zach's Computer Store Database
This project is centered around developing a streamlined relational database for Zach’s Computers, designed to support efficient retail and inventory management. The system organized core business data across products, brands, categories, suppliers, customers, orders, payments, shipments, inventory and returns. Each table captures essential details such as product specifications, stock levels, customer information and transaction histories. This is all done while maintaining clear relational links that support the accurate tracking of sales, order fulfillment, and inventory. This database was built in full compliance with third normal form (3NF), meaning data integrity was preserved and the database will serve as a reliable foundation for reporting. This will offer a structured solution to help Zach’s Computers manage and analyze its daily business activities with greater efficiency and precision.
